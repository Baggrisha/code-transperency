# Иконки из предоставленной айдентики

`reference-sheet.png` — исходный лист пользователя: 1280×720 px, RGB, 20 иконок. Пиксели не перерисованы. Контрольная сумма исходника и координаты окон 112×112 px записаны в `manifest.json`.

В интерфейсе используется один PNG через `../icons.css`: класс `.identity-icon` задаёт общий спрайт, `.identity-icon--folder` и аналогичные классы выбирают окно. CSS масштабирует каждое окно вместе с элементом; все 20 окон доступны независимо от того, какие используются на текущем экране.

Исходный лист не содержит прозрачного канала. Синий фон и локальные свечения входят в предоставленную графику и сохранены. Это растровые изображения, а не восстановленные векторные контуры.

## Отдельные файлы

```bash
python scripts/export_icons.py --output-dir /tmp/uzniki-icons --zip /tmp/uzniki-icons.zip --catalog /tmp/uzniki-icons.html
```

Команда создаёт 20 самостоятельных SVG-файлов. Каждый SVG показывает соответствующее окно исходного PNG и содержит изображение внутри файла, поэтому не требует соседних ресурсов. Каталог `index.html` позволяет просмотреть и скачать отдельные иконки. В архив также включены неизменённый PNG, manifest и пояснение к формату.

Внешние SVG из каталога являются контейнерами растровой графики. Не следует обозначать их как заново нарисованный вектор или прозрачные PNG.
