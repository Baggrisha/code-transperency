## Вопросы к Грише

1. **Стабильность `signal.id`.** `engine._Context.signal` хеширует весь сигнал вместе с текстом `title`/`explanation`. На этом построены `prior_reviews`: правка формулировки в движке «отвяжет» прежние решения. Нужно подтвердить, что это ожидаемо, или договориться об id без текста.
2. **`positions[].complete`.** В примере «8 поставлено из 10» приходит `complete: true`. По README это «данных достаточно», а не «поставка завершена». Подтвердить смысл, чтобы Маша не подписала поле как «Поставлено полностью».
3. **Устаревшие артефакты.** `reports/unittest.txt` и `reports/build_manifest.json` относятся к прошлой версии (это написано в README). Перегенерировать перед сдачей.
4. **Паспорт и `docs/technical_description.docx`.** Добавить PDF-экспорт, журнал `GET /api/runs`, CORS по умолчанию.
5. **Тесты на Python 3.13** выдают `StarletteDeprecationWarning` про `httpx` в `TestClient`. На работу не влияет, но версии зависимостей зафиксированы Гришей — менять без него не стал.

Алгоритмы извлечения, нормализации и сверки (`extract.py`, `normalize.py`, `engine.py`, `models.py`) **не изменялись**.
